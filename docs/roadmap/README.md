## 项目愿景

**愿景**：成为"人类在环"的 AI 研发自动化基础设施，让团队既能享受 AI 自动化效率，又保持必要的控制。

**核心定位**：ClawKit 是一个轻量级任务编排工具，通过审批流确保 AI 执行的可控性，通过一键部署降低使用门槛。

---

## 当前状态

| 维度 | 完成度 | 说明 |
|-----|-------|------|
| 核心链路 | 90% | webhook → 草稿 → 审批 → 派发 → 执行 → 回传 |
| 一键部署 | 80% | 单机模式全自动，混合/双机半自动 |
| 文档完善度 | 90% | 80+ 篇文档，但存在同步问题 |
| 测试覆盖 | 50% | controller 较全，CLI/shared/web 薄弱 |
| 生态建设 | 10% | 尚未开始 |

详细状态见 [status.md](./status.md)

## 如何参与

1. 选择一个任务包文档（tasks-v0.2.md 等）
2. 从 P0 优先级任务开始
3. 创建分支，标记任务状态为 in_progress
4. 完成开发后更新任务状态为 completed
5. 提交 PR，关联相关任务

详细流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)（待创建）
