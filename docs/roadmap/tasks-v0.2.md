| 状态 | 🔴 待开始 |
| 预计工时 | 8h |
| 负责人 | - |

**任务描述**
为 CLI 命令添加单元测试，覆盖核心命令

**验收标准**
- [ ] init 命令测试覆盖
- [ ] doctor 命令测试覆盖
- [ ] plan 命令测试覆盖
- [ ] apply 命令测试覆盖
- [ ] heal 命令测试覆盖

**测试场景**
```
init:
  - 生成简化配置
  - 生成完整配置
  - 指定输出路径

doctor:
  - 配置文件存在
  - 配置文件不存在
  - 配置格式错误

plan:
  - dry-run 输出正确
  - 输出 JSON 格式

apply:
  - dry-run 不写入文件
  - 实际写入文件
  - 配置错误拒绝执行

heal:
  - 检测到问题
  - 无问题不修复
  - --dry-run 模式
```
